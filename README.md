# LDRC — قالب ووردبريس للمركز الليبي لأبحاث طب الأسنان

قالب مخصص بالعربية (RTL) لموقع المركز الليبي لأبحاث طب الأسنان.

## التثبيت

1. حمّل المستودع بصيغة ZIP (Code ← Download ZIP).
2. من لوحة ووردبريس: **المظهر ← قوالب ← إضافة جديد ← رفع قالب**، ثم ارفع الملف وفعّله.
3. اضبط لغة الموقع على العربية من **الإعدادات ← عام**.
4. من **الإعدادات ← روابط دائمة** اختر "اسم المقالة"، ثم اضغط حفظ.

## أقسام الموقع

| القسم | مكانه في لوحة التحكم | الرابط |
|---|---|---|
| الأخبار | المقالات | أنشئ صفحة فارغة باسم "الأخبار" وعيّنها "صفحة المقالات" من **الإعدادات ← القراءة** |
| الأبحاث والبيانات | الأبحاث والبيانات (+ مجالات البحث) | `/research` |
| الفعاليات | الفعاليات | `/events` |
| المؤتمرات | المؤتمرات | `/conferences` |
| الشركاء | الشركاء (الشعار = الصورة البارزة) | `/partners` |
| اتصل بنا | صفحة جديدة بقالب **"صفحة اتصل بنا"** | — |

لكل فعالية ومؤتمر وبحث صندوق **"التفاصيل"** على جانب المحرر، وفيه التاريخ والمكان ورابط التسجيل أو الملف.
تظهر الفعاليات والمؤتمرات القادمة أولاً في الصفحة الرئيسية، وتحمل شارة "قادم".

## التعديل بدون برمجة

**المظهر ← تخصيص ← إعدادات موقع المركز**:

- الألوان: الأساسي والثانوي والداكن.
- الواجهة الرئيسية: العنوان والنص وصورة الخلفية والأزرار.
- عن المركز، والرؤية والرسالة.
- الأرقام والإحصائيات (4 أرقام).
- مجالات العمل (4 مجالات).
- معلومات التواصل والخريطة وبريد استقبال الرسائل.
- حسابات التواصل الاجتماعي.

الشعار من **تخصيص ← هوية الموقع**. القوائم من **المظهر ← القوائم** (الرئيسية والتذييل). إذا لم تُنشأ قائمة يظهر رابط لكل قسم تلقائياً.

## ملاحظات

- كل النصوص الحالية مؤقتة، وتُستبدل عند استلام المحتوى الرسمي والشعار والألوان من المركز.
- الأقسام الفارغة تعرض بطاقات "سيتم الإضافة قريباً" إلى أن يُضاف المحتوى.
- نموذج التواصل لا يحتاج إضافة، ويرسل عبر `wp_mail`. يُفضّل تثبيت إضافة SMTP على الاستضافة لضمان وصول الرسائل.
